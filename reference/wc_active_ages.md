# Primary active-age vectors per cohort (ret==FALSE + ABU net-new appended to URPS).

Primary active-age vectors per cohort (ret==FALSE + ABU net-new appended
to URPS).

## Usage

``` r
wc_active_ages(coh, abu_age = wc_load_abu_ages())
```

## Arguments

- coh:

  \[data.frame\]: Cohort from \`wc_load_cohort()\`.

- abu_age:

  \[integer\]: ABU urology-pathway ages to append for the both-pathway
  baseline.
