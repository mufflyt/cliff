# One-line human phrasing of an uncertainty summary row, for logs / captions.

One-line human phrasing of an uncertainty summary row, for logs /
captions.

## Usage

``` r
wc_uncertainty_sentence(u, unit = "urogynecologists")
```

## Arguments

- u:

  \[list\]: Uncertainty summary to render.

- unit:

  \[character\]: Noun for the quantity being described.
