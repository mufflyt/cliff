# Add fellowship inference to Table 1 pipeline

Add fellowship inference to Table 1 pipeline

## Usage

``` r
add_fellowship_to_table1(physicians, temporal_db_path = NULL)
```

## Arguments

- physicians:

  \[data.frame\]: Physician table to augment with inferred fellowship
  columns.

- temporal_db_path:

  Path to temporal NPPES database

## Value

Enhanced data frame with fellowship inference columns
