# Per-band hazard lookup (missing bands filled with the max, capped at 1).

Per-band hazard lookup (missing bands filled with the max, capped at 1).

## Usage

``` r
wc_haz_for(age, hz)
```

## Arguments

- age:

  \[numeric\]: Ages to look the hazard up for.

- hz:

  \[numeric\]: Named age-band hazard vector.
