# Path to the Medicare signals DuckDB database

Convenience wrapper for \`wc_path("signals_duckdb")\` — the resolved
path to the external Medicare fee-for-service signals DuckDB that the
workforce pipeline reads from.

## Usage

``` r
wc_duckdb_path()
```

## Value

A length-1 character filesystem path to the signals DuckDB.

## See also

\[wc_path()\].

## Examples

``` r
if (FALSE)  wc_duckdb_path()  # \dontrun{}
```
